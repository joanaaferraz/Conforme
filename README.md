# Ramo «dados»

Projetos que o plugin Conforme envia para a app do iPhone, **cifrados com senha** (ver `schema/conforme-cifrado.md` no ramo main).
Cada ficheiro `p/<código>.json` é um envelope AES-GCM; sem a senha não se consegue ler.
Este ramo é escrito pelo plugin. Não é publicado no site da app.
